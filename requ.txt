🔄 DATA FLOW ARCHITECTURE
Frontend to Backend Communication
text
User Action → API Call → Server Processing → Database Update → Response → UI Update
Example: Rating a Gym
1. User clicks star rating on gym page
2. Frontend sends POST /api/gyms/gyms/:gymId/rate
3. Server validates user authentication
4. Database updates gym rating and user rating record
5. Server recalculates average rating
6. Response returns updated gym data
7. Frontend updates UI with new rating
Real-time Updates
* Rating changes immediately reflect in UI
* Comment counters update in real-time
* Online status indicators for messaging
* Live notification badges
